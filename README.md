# Movie Ticket Booking Application

A movie ticket booking application developed using Kotlin in Android Studio. The application allows users to browse movies, select cinemas and showtimes, choose seats, book tickets, and view booking history.

---

## ✨ Features

- User Authentication (Login & Register)
- Browse Movies
- Select Cinemas & Showtimes
- Seat Selection
- Ticket Booking
- Booking History Management
- Real-time Data Handling
- Responsive User Interface

---

## 🛠 Tech Stack

- Kotlin
- Android Studio
- Volley
- RESTful APIs
- XML Layout

---

## 🌐 API Integration

The application uses the **Volley library** to communicate with APIs for:
- GET
- POST
- PUT
- DELETE

These APIs are used to manage authentication, movies, cinemas, showtimes, seats, bookings, and booking history.

## 🚀 Getting Started

### 1. Clone Repository

```bash
git clone https://github.com/Giang-ASAG/BookingTicketskotlin.git
```

### 2. Open Project

Open the project using **Android Studio**.

### 3. Configure API

Update the API base URL inside the configuration file.

Example:

```kotlin
const val BASE_URL = "https://your-api-url.com/"
```

### 4. Run Application

Connect an Android device or start an emulator, then run the application.
